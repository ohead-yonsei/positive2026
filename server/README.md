# 유령 추첨 배포

`Raffle.gs`는 비밀 정보가 없는 서버 코드다. Apps Script 프로젝트에 같은 이름의 파일로 추가한다.
기존 `Gift.gs`의 이미지 상수 `GIFT_IMG`는 그대로 두고, 함수만 다음으로 교체한다.

```js
function giftAction(q) {
  return raffleAction(q);
}
```

`Code.gs`의 `handle()`은 이미 ScriptLock을 잡은 상태에서 이 함수를 호출하며,
`isAdmin(q)`로 기존 운영진 비밀번호를 검증한다. 해당 파일과 실제 기프티콘을 저장소에 올리지 않는다.
기존 웹 앱 배포를 새 버전으로 업데이트하여 URL을 유지한다.

- 한국시간 2026-10-31 00:00:00 전에 서버가 받은 응모만 집계한다. 별도 트리거는 필요 없다.
- 100회마다 한 장, 이름별 최대 다섯 장이다. 기존 로컬 횟수는 첫 응모 때 포함한다.
- 같은 브라우저의 응모 확인 토큰을 해시로 보관한다. 재전송은 누적 횟수의 최댓값만 반영한다.
- 마감 후 `#admin`에서 추첨하며 결과와 응모권 스냅샷을 한 번 저장한다. 재추첨 API는 없다.
- `gift`에 기존 지급 기록이 있다면 이를 보존하고 새로운 지급을 막는다. 기존 토큰의 조회는 유지한다.
- 이전 `claim` 요청은 거절한다. 공개 응답에는 이미지·응모 토큰·토큰 해시가 없다.
- 브라우저 저장소를 지우면 자동 선물 조회 권한을 잃는다. 친구들끼리 쓰는 기존 신뢰 모델에 따라 이름 본인인증이나 클릭 조작 방지는 하지 않는다.

`node --test tests/raffle.test.cjs`로 가짜 저장소·시계·기프티콘을 사용해 검증한다.
실서버에 응모·추첨·수령 테스트 요청을 보내지 않는다.
